# Origami — 产品需求规格说明书

> 最后更新: 2026-07-21

## 一、产品定位

**个人内容档案馆（Personal Content Archive）** — 多平台内容备份与管理工具。

不是"下载器"或"去水印工具"。核心差异：订阅 + 增量同步 + 跨平台聚合。

## 二、目标用户

| 层级 | 用户 | 需求 |
|------|------|------|
| 主力 | 任新田本人 | 全功能 |
| 普通用户 | 不懂技术的普通人 | 粘贴链接就能用，简洁 UI |
| 技术用户 | 二次开发者 | CLI 接口 + 开源 |

## 三、核心场景

1. **随手存**: 复制链接 → 自动识别 → 一键下载
2. **订阅同步**: 关注博主 → 自动发现新作品/直播 → 弹窗提醒 → 选择下载
3. **个人备份**: 管理自己主页的喜欢、收藏、音乐、合集，每次打开自动同步

## 四、平台支持

| 平台 | 优先级 | 时间 | 范围 |
|------|--------|------|------|
| 抖音 | ✅ 已完成 | — | 7 种模式 |
| B站 | 🔴 下一个 | 2周内 | 视频下载 → 合集 → 番剧 |
| 微博 | 🟡 | 2周内 | 待定 |
| 快手 | 🟡 | 2周内 | 待定 |
| 小红书 | 🟡 | 2周内 | 待定 |
| YouTube | ❌ | 不做 | — |

## 五、桌面端 UI

- **风格**: Obsidian 风格 — 简洁工具型，当代设计
- **布局**: 左侧边栏 + 主内容区（统一输入框）
- **统一输入框**: 粘贴任意平台链接 → 自动识别平台/类型 → 加载数据 → 显示作者信息 + 预览 + 下载按钮
- **主题**: CSS 变量驱动，可 DIY 切换
- **侧边栏**: 首页 / 订阅 / 主页(喜欢收藏音乐) / 直播(订阅+手动) / 设置 / 更多（借鉴滴答清单）

## 六、订阅系统

- **订阅名单**: Origami 内单独维护
- **添加方式**: 粘贴主页链接 / 手动输入
- **增量同步**: 每次打开 + 每 1 小时检查
- **新作品通知**: 弹窗提醒，可全部下载 / 勾选下载 / 稍后再说
- **已读标记**: 下载后标记

## 七、设置项

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 下载路径 | output/抖音 | 可自定义 |
| 图片格式 | jpeg | webp / jpeg / jpg |
| 线程数 | 30 | 1-50 |
| 长视频 | 跳过 >30min | 可关闭 |
| 登录管理 | — | 各平台扫码登录 |
| 主题切换 | 暗色 | 多套预设 |
| 自动更新 | 开 | — |
| 重试次数 | 3 | — |
| 代理设置 | 无 | — |
| 关于页 | — | 作者/项目/捐赠/反馈/更新日志/隐私/免责/版权/协议/许可 |

## 八、移动端（远期）

- **Android**: 悬浮窗 + WebView 桥
- **iOS**: 共享 Sheet 扩展
- **桌面端先稳定再推进**

## 九、分发

- 安装器 (Inno Setup) + 绿色免安装包
- 自动更新 (GitHub Release)
- 开源 + 捐款通道

## 十、不做什么

- ❌ 不做 Web 服务 / API 对外开放
- ❌ 不做付费内容破解
- ❌ 不做 YouTube
- ❌ 不做内置文件管理器（用系统资源管理器）
- ❌ 不收集用户数据上传

## 十一、CLI 已实现

```bash
python -m src.main cli <链接>                    # 自动识别
python -m src.main cli single|batch|like|collection|mix|music|live <链接>
python -m src.main login|server|dev
```
